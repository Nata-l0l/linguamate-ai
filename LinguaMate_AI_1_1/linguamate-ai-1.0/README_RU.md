# LinguaMate AI 1.0 — отдельная новая версия

Старая версия 0.2 не затрагивается. Этот проект — самостоятельный PWA-прототип.

## Что уже работает
- адаптивный интерфейс для компьютера и телефона;
- переключение интерфейса English / Español / Русский;
- выбор родного языка, изучаемого языка и уровня CEFR;
- разделы Home, AI Tutor, Vocabulary, Real Life, Progress, Settings;
- локальное сохранение настроек и слов в браузере;
- добавление, поиск, отметка выученных слов и удаление;
- экспорт локальных данных в JSON;
- PWA manifest и service worker;
- серверная Netlify Function для OpenAI API (ключ не хранится в браузере).

## Важно
Регистрация пользователей, синхронизация между устройствами и платежи пока не подключены. Слова и настройки хранятся локально в браузере этого устройства. Без переменной `OPENAI_API_KEY` чат работает в демонстрационном режиме. Это честно обозначено в интерфейсе.

## Публикация на Netlify (рекомендуемый способ — отдельный новый сайт)
1. Распакуйте ZIP.
2. Создайте новый сайт в Netlify, не выбирая старый `wonderful-kashata-05780a`.
3. Чтобы работали Netlify Functions, подключите папку к отдельному репозиторию GitHub и импортируйте его в Netlify. В корне проекта уже есть `netlify.toml`.
4. В Netlify откройте Site configuration → Environment variables и добавьте `OPENAI_API_KEY` со своим секретным ключом. Не вставляйте ключ в `app.js`, `index.html` или сообщения чата.
5. Сделайте новый deploy. Для функции нужен deploy через Git/Netlify CLI; простой drag-and-drop может опубликовать статику, но не настроить функции как полноценный Git deploy.

## Локальный просмотр
Откройте `index.html` двойным щелчком. Основной интерфейс и локальные функции будут доступны. Для корректной проверки PWA и Netlify Function нужен HTTPS-хостинг.

## Текущие ограничения MVP
- нет регистрации / Supabase;
- нет облачной синхронизации;
- нет реальной оплаты;
- нет голосовых функций;
- AI требует настроить ключ и проверить API-биллинг OpenAI отдельно.


## Обновление 1.1 — AI Tutor

В этой сборке добавлены: выбор языка и уровня прямо в чате; многоходовой диалог с передачей контекста; мягкое исправление ошибок; локальная история бесед; карточки полезных слов с кнопкой сохранения в словарь. История и словарь хранятся локально в браузере этого устройства (не синхронизируются между устройствами).

### Включение настоящего ИИ на Netlify
1. Загрузите проект через GitHub (для Netlify Functions нужен Git-деплой; обычный drag-and-drop публикует только статические файлы).
2. В Netlify откройте Site configuration → Environment variables.
3. Добавьте `OPENAI_API_KEY` со своим секретным API-ключом OpenAI. Не вставляйте ключ в `app.js`, HTML или другие публичные файлы.
4. При желании добавьте `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`).
5. Запустите новый deploy. Проверьте AI Tutor: отправьте сообщение на изучаемом языке.

Без переменной `OPENAI_API_KEY` чат честно покажет сообщение о том, что ИИ не настроен; он не будет выдавать демонстрационные ответы за настоящий ИИ.

### Важно
- Беседы, настройки и словарь сохраняются в localStorage на текущем устройстве. Очистка данных браузера может их удалить.
- Для аккаунтов и синхронизации между iPhone и компьютером следующим этапом подключим Supabase Auth и базу данных.
- API-запросы оплачиваются отдельно по тарифам OpenAI API. Задайте лимиты бюджета в кабинете OpenAI.
